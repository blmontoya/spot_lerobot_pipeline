# Spot LeRobot Pipeline

This repository contains the dataset processing and formatting tools required to convert Boston Dynamics Spot ROS 2 recordings into the standard LeRobot format for imitation learning policy training.

This repo is meant to be accompany **[spot_ros2_multi_ws](https://github.com/blmontoya/spot_ros2_multi_ws)**

## Environment Setup

Ensure you are using the dedicated Conda environment before executing scripts:

```bash
conda activate lerobot
